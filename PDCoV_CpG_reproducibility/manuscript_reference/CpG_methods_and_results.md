# Manuscript reference: dinucleotide composition and CpG relative abundance

## Methods text represented by this workflow

The analysis uses 265 non-recombinant PDCoV whole-genome records. A custom Bash workflow splits the multi-FASTA file into individual genome files. Dinucleotide frequencies are calculated with `compseq` from EMBOSS v6.6.0, using word size 2 and the `-calcfreq` option. For each genome, observed frequencies, expected frequencies based on mononucleotide composition, and observed-to-expected (O/E) ratios are obtained for all 16 dinucleotide types. Individual outputs are combined for downstream statistical analyses.

For temporal analysis, each genome's CpG O/E ratio is paired with its sampling year. Spearman rank correlation is used to evaluate the association, and a bootstrap procedure estimates the 95% confidence interval. Annual medians and interquartile ranges are summarized; linear regression characterizes the temporal trend. Leave-one-year-out analyses assess robustness. Generalized additive models (GAMs) assess potential nonlinear temporal patterns, with fit summarized by effective degrees of freedom (EDF), adjusted R-squared, and percentage deviance explained. Only genomes with unambiguous sampling dates are included in temporal analyses. All dinucleotide analyses are performed at the whole-genome level.

## Results values previously established in the project

The current project record reports:
- Spearman's rho = -0.465
- Bootstrap 95% CI = [-0.562, -0.358]
- P < 0.001
- GAM sensitivity checks at k = 4, 6, 8, and 10 gave EDF approximately 1.0, adjusted R-squared approximately 0.189, and deviance explained approximately 19.2%.

These values are reference values from the prior analysis record, not outputs generated by this archive. Re-run the scripts on the final input files and confirm that the values match before using them in the manuscript.

## Important distinction

The manuscript specifies EMBOSS `compseq` v6.6.0. This package therefore uses `compseq` as the source of per-genome dinucleotide observed/expected values. An independent R implementation of dinucleotide O/E may differ in its treatment of ambiguous bases, gaps, sequence ends, and expected-frequency calculation. Do not describe an alternative implementation as equivalent unless per-genome results have been compared and equivalence has been demonstrated.
